# 视频设置与本地命令

在游戏内打开「选项 → 视频设置」，找到 Prime PT 的画质、显示或光照选项。也可以打开**游戏聊天框**，输入下表中的 `/pt` 命令。命令无需服务端权限。

例如，输入 `/pt spp` 查看当前每像素采样量，输入 `/pt spp 1` 将它设为 1，输入 `/pt reset` 恢复默认。设置保存在当前游戏实例的 `config/prime_pt.properties`。

渲染设置按三层排列：先打开 Prime PT，再选择实时或离线模式，实时模式下再选择普通 PT 或 ReSTIR PT Enhanced。ReSTIR 使用邻近像素和前帧的光线路径参与采样。上层关闭时下层控件停用，原有选择保留。关闭 Prime PT 后恢复原版世界绘制，并释放 Prime 的世界及屏幕工作集；启动时协商的显卡能力仍保留。

选择「离线快照」后，固定最近一次成功绘制的场景、相机、路径预算和光照，以完整窗口分辨率持续累积普通 PT；没有可用帧时先等待首帧。游戏逻辑继续运行，手部隐藏，菜单仍可操作。可以修改每帧采样量和显示参数。切回实时后继续处理世界变化；切换世界或资源重载会结束旧快照。离线选择只在本次会话有效，重启恢复实时。调整窗口大小或重新进入离线会重新累积。

| 命令 | 默认与范围 |
| --- | --- |
| `/pt enabled on\|off` | 默认开启；关闭恢复原版，保留实时渲染器偏好。 |
| `/pt mode realtime\|offline` | 默认 `realtime`；离线不使用 RR。 |
| `/pt renderer path_trace\|restir_pt` | 默认 `path_trace`，仅决定实时模式的积分器。 |
| `/pt mcap 数量` | ReSTIR 时间复用每步最多带入的历史量，默认20，范围1–100。 |
| `/pt fresh 百分比` | ReSTIR 输出独立选择本帧初采结果的概率，默认40%，范围0–100%。 |
| `/pt diagnostic on\|off` | 默认关闭；实时模式下使用原生分辨率、每帧1个样本，关闭RR和跨帧图像累积。 |
| `/pt ser on\|off`、`/pt rr on\|off` | 默认开启，设备能力不足时回退。 |
| `/pt quality 档位` | `dlaa`、`quality`、`balanced`、`performance`（默认）、`ultra_performance` |
| `/pt spp 数量`、`/pt bounces 顶点数` | 默认 1 和 12，范围均为 1–64。 |
| `/pt ev EV` | 默认 0，范围 −16 至 16。设定自动曝光后的手动补偿，`exposure` 是别名。 |

「PT 显示」的自动曝光强度默认 65%，设为 0% 可关闭自动调节。Prime DRT 的饱和度补偿、色相补偿和压缩起点默认分别为 5%、75% 和 0.4。

离线快照继承进入前的自动曝光并保持不变；改变自动曝光强度会即时重新测光一次。手动曝光和显示曲线变化保留已积累的线性样本。

「PT 光照」可调整观测纬度、季节、太阳强度和方块发光强度。太阳轨迹默认北纬 30°、太阳黄经 0°（春分）。两项发光强度默认 0 EV，步长 0.25 EV，范围分别为 −8 至 8 EV 和 −10 至 10 EV。

「区块更新」控制每轮工作量。常驻内存额度独立设置。

| 档位 | 捕获 section | 建网 slab | 几何 quad | 属性 quad |
| --- | ---: | ---: | ---: | ---: |
| 平稳 | 16 | 48 | 65,536 | 131,072 |
| 平衡（默认） | 32 | 96 | 131,072 | 262,144 |
| 吞吐 | 64 | 128 | 262,144 | 524,288 |

SPP 是每像素的采样次数，顶点数限制一条光线路径处理的表面交点数量。提高两者通常增加显卡工作量，可以先保留默认值，观察同一场景的帧率再调整。

实时 ReSTIR 使用每帧一个初始路径候选和时空复用，因此采样数滑块停用；普通 PT 和离线模式沿用 1–64。两种实时积分器均可使用已准备的SER阶段和RR。相机、日照、局部区块/属性与SER变化保留时间历史；几何删除或重建只拒绝涉及该mesh的旧路径。视图每轴最多4096像素；效果和成本仍需按实际游戏场景比较。历史失效范围见[诊断手册](diagnostics.md#时间历史的显式管理)。

「ReSTIR 初采输出比例」按固定概率为每个像素选择初采或复用估计：0%全部复用，100%全部初采。复用阶段和路径历史始终保留，输出选择只改变显示的估计，不反馈路径历史。此项与历史M上限都可在实时ReSTIR下调整。

「原生无累积诊断」保留当前积分器的内部采样方式、ReSTIR复用、显示曝光和色调映射。它停用RR、画质和SPP控件，每帧只显示当前样本。退出后沿用原来的RR、画质与SPP偏好；离线模式下诊断停用，继续累积离线图像。

画质菜单反映请求的 RR 档位。Performance 的输入每轴通常约为输出的一半，实际尺寸以 SDK 查询为准。检查设备实际生效的能力和回退原因时，见[诊断](diagnostics.md)。
