# 视频设置与本地命令

在游戏内打开「选项 → 视频设置」，找到 Prime PT 的画质、显示或光照选项。也可以打开**游戏聊天框**，输入下表中的 `/pt` 命令。命令无需服务端权限。

例如，输入 `/pt spp` 查看每像素的采样次数，输入 `/pt reset` 恢复默认。设置保存在当前游戏实例的 `config/prime_pt.properties`。

先打开 Prime PT，再选择实时或离线模式。上层关闭时下层控件停用，原有选择保留。关闭 Prime PT 后恢复原版世界绘制，并释放 Prime 的世界及屏幕工作集；启动时协商的显卡能力仍保留。

选择「离线快照」后，固定最近一次成功绘制的场景、相机、路径预算和光照，以完整窗口分辨率持续累积普通 PT；没有可用帧时先等待首帧。游戏逻辑继续运行，手部隐藏，菜单仍可操作。可以修改每帧采样量和显示参数。切回实时后继续处理世界变化；切换世界或资源重载会结束旧快照。离线选择只在本次会话有效，重启恢复实时。调整窗口大小或重新进入离线会重新累积。

| 命令 | 默认与范围 |
| --- | --- |
| `/pt enabled on\|off` | 默认开启；关闭恢复原版，保留实时渲染器偏好。 |
| `/pt mode realtime\|offline` | 默认 `realtime`；离线不使用 RR。 |
| `/pt diagnostic on\|off` | 默认关闭；实时模式使用原生分辨率，关闭RR和跨帧图像累积；普通PT保留每帧SPP。 |
| `/pt denoiser dlss\|nrd\|off` | 实时降噪器。默认选择 DLSS，缺少 DLSS 时自动选用设备支持的 NRD。旧配置的 `rr=false` 对应关闭。 |
| `/pt ser on\|off`、`/pt rr on\|off` | SER 开关和旧版 DLSS 开关。 |
| `/pt quality 档位` | `dlaa`、`quality`、`balanced`、`performance`（默认）、`ultra_performance` |
| `/pt spp 数量` | 实时固定为 2。离线可设置每批 1–64 条路径，默认为 1。旧配置中的采样数会作为离线批大小读取。 |
| `/pt bounces 顶点数` | 默认12，范围1–64。 |
| `/pt ev EV` | 默认 0，范围 −16 至 16。设定自动曝光后的手动补偿，`exposure` 是别名。 |

在视频设置中选择「降噪器」，或输入 `/pt denoiser nrd` 以原生分辨率使用 NRD。它单独过滤太阳阴影、漫反射和高光。静止场景的间接光照历史最多保留 63 帧，太阳阴影最多保留 7 帧。大幅跳转相机、切换降噪器或重建视图会重置历史。DLSS 的质量档控制 DLSS 的输入分辨率。

要试用 LabPBR 资源包，在游戏「选项 → 资源包」打开资源包文件夹，把 ZIP 放进去，返回选择它并点击「完成」。查看受阳光照射的金属、钻石块和暗处的萤石，可以分别检查反射、法线与自发光。资源包可单独覆盖法线图（`_n`）和材质图（`_s`），并沿用原版底色。当前材质图集使用动画的首个指定帧。高度视差、环境遮蔽和孔隙吸水属于可选效果，当前材质路径使用法线、平滑度、反射率、薄表面散射和自发光。[LabPBR 材质规范](https://shaderlabs.org/wiki/LabPBR_Material_Standard)

发光方块的任一材质纹理指定了发光区域时，只有纹理标出的区域会发光。整个方块都没有指定发光区域时，使用原版亮度。次表面散射目前用于薄片，苔藓块等有厚度的方块使用漫反射。

在暗处把海晶灯依次放在地上、丢在地上、装入物品展示框和拿在手里，可以对照同一张纹理的发光区域。第一人称只向世界提交手里的发光物品，自己的角色模型在第三人称出现。移动灯会随物品位置照亮周围。

开发时可在 mod 根目录的 PowerShell 运行 `.\gradlew.bat labPbrFixture "-PlabPbrPack=C:\资源包\SPBR-22_6.zip"`，再运行 `cargo test --release -p prime_minecraft spbr_materials_reach -- --ignored`。看到 `1 passed` 表示测试贴图已通过游戏资源栈、解码和图集检查。若未生成数据，先检查 ZIP 路径和 Gradle 输出。

在视频设置的「PT 显示」中开启「镜头泛光」，用「泛光模式」选择外观。

- **快速圆形**是默认值，以理想圆孔衍射为参考，保留紧凑的亮核和柔和的圆晕，GPU 开销较低。
- **相机光圈（camara）**让太阳和亮点使用工作台导出的 `camara.rgb32le` 衍射核。
- **瞳孔（pupil）**使用工作台导出的 `pupil.rgb32le` 衍射核。

选择在下一帧生效，实时和离线快照共用。关闭再开启会恢复上次选择。升级前选了「十二芒」或「近圆光瞳」的配置分别迁移到「相机光圈」和「瞳孔」。

自动曝光强度默认 65%，设为 0% 可关闭自动调节。Prime DRT 的饱和度补偿、色相补偿和压缩起点默认分别为 5%、75% 和 0.4。

离线快照继承进入前的自动曝光并保持不变；改变自动曝光强度会即时重新测光一次。手动曝光和显示曲线变化保留已积累的线性样本。

「PT 光照」可调整观测纬度、季节、太阳强度和方块发光强度。太阳轨迹默认北纬 30°、太阳黄经 0°（春分）。两项发光强度默认 0 EV，步长 0.25 EV，范围分别为 −8 至 8 EV 和 −10 至 10 EV。

「区块更新」控制每轮工作量。常驻内存额度独立设置。

| 档位 | 捕获 section | 建网 slab | 几何 quad | 属性 quad |
| --- | ---: | ---: | ---: | ---: |
| 平稳 | 16 | 48 | 65,536 | 131,072 |
| 平衡（默认） | 32 | 96 | 131,072 | 262,144 |
| 吞吐 | 64 | 128 | 262,144 | 524,288 |

SPP 是每像素的采样次数，顶点数限制一条光线路径处理的表面交点数量。提高两者通常增加显卡工作量，可以先保留默认值，观察同一场景的帧率再调整。

实时普通 PT 固定使用质量采样，每像素两条路径。实时和离线都使用平方根俄罗斯轮盘赌，以折射率补偿后的吞吐决定存活概率，存活路径按实际概率补偿。首表面仍按重建需要选择：界面高光反射与进入材质内部（含漫反射、次表面散射）各取一半选择概率；2 spp分别覆盖两个半区。纯金属使用两条高光路径。后续反弹仍按材质概率。离线保留原材质概率，可用命令设置1–64的批次大小。非delta表面分别采太阳盘和局部灯，天空其余方向由BSDF路径覆盖。实时模式可使用已准备的SER阶段和RR。相机、日照、局部区块/属性与SER变化保留RR历史。视图每轴最多4096像素；效果和成本仍需按实际游戏场景比较。历史失效范围见[诊断手册](diagnostics.md#时间历史的显式管理)。

四阶段实时PT和首面分离需要设备启用 `VK_EXT_ray_tracing_invocation_reorder` 能力；在具备该能力的设备上关闭SER排序，仍然保留四阶段与首面策略。设备缺少此能力时使用兼容完整路径，每条路径按原材质概率采样。

「原生无累积诊断」停用RR和画质控件，保留显示曝光和色调映射。普通PT使用无guide、按原材质概率采样的完整路径参考，只平均本帧样本，下一帧显式重开RGB样本域。输入 `/pt diagnostic on` 可观察每帧两条参考路径。退出后沿用原来的 RR 与画质偏好；离线模式下诊断停用，继续累积离线图像。

画质菜单反映请求的 RR 档位。Performance 的输入每轴通常约为输出的一半，实际尺寸以 SDK 查询为准。检查设备实际生效的能力和回退原因时，见[诊断](diagnostics.md)。
